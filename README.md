# OneLineage

The tree-of-life tool in the OneOrigin suite. Coming soon.

> **Status: coming soon.** This repo holds the name, the license and the suite's brand files. There's no code and no plan yet, so nothing has been tested. The plan and its decisions get written here first, before any code.

## Where it fits

OneLineage is one of five independent tools in the [OneOrigin suite](https://github.com/ExtantApe/OnePhylogeny/blob/main/docs/oneorigin/README.md), from EXTANT APE. The suite runs from the widest view to the closest: [OneTaxonomy](https://github.com/ExtantApe/OneTaxonomy), OneLineage, [OnePhylogeny](https://github.com/ExtantApe/OnePhylogeny), [OnePedigree](https://github.com/ExtantApe/OnePedigree) and [OneFamily](https://github.com/ExtantApe/OneFamily). OneLineage sits between OneTaxonomy, which shows what sources claim about how life is classified, and OnePhylogeny, which tests DNA against reference panels.

Like the others, it will work on its own, with no account and no subscription, and keep your work in plain files you can read without it.
